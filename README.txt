SALAIRE 39H - VERSION PWA COMPLETE

Cette archive contient la version complète prête à déposer sur GitHub Pages.

Structure :
- index.html : page d'accueil
- manifest.webmanifest : manifeste PWA de la page d'accueil
- sw.js : service worker de la page d'accueil
- app/index.html : simulateur
- app/manifest.webmanifest : manifeste PWA du simulateur
- app/sw.js : service worker du simulateur
- app/icons/icon-192.png : icône PWA
- app/icons/icon-512.png : icône PWA

Pour Android : ouvrir directement
https://aude202.github.io/Salaire39H/app/

Puis dans Chrome : menu ⋮ -> Installer l'application (ou Ajouter à l'écran d'accueil).

Après remplacement des fichiers sur GitHub Pages, attendre quelques minutes et, si nécessaire,
actualiser/vider les données du site dans Chrome pour forcer la prise en compte du nouveau manifeste.
